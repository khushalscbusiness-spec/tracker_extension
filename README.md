# JobPulse Tracker Extension

A Chrome extension that helps you track job applications with one click.

## Features

- 🔍 Automatically detects job details from job pages
- 📌 Track jobs with a single click
- 🔄 Detects duplicate jobs across platforms
- 🔐 Secure authentication with JobPulse backend
- 📊 Syncs with your JobPulse dashboard
- 🌐 Supports LinkedIn, Naukri, and generic career pages

## Installation

### Development Setup

1. Clone this repository
2. Load the extension in Chrome:
   - Open `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select the `dist` folder

### Build for Production

./build.sh
